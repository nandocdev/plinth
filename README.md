# Plinth — Multi-tenant SaaS Engine

> ⚠️ **Legacy architecture exploration.** Plinth is preserved as a public reference for an earlier multi-tenant SaaS architecture.

This repository documents an earlier implementation of a Laravel multi-tenant SaaS engine. It remains useful as an architectural reference, but it is not the canonical implementation of the current NandocDev SaaS foundation.

## Status

- **Status:** legacy / reference
- **Purpose:** architecture exploration
- **Current SaaS foundation:** see [laraShift](https://github.com/nandocdev/laraShift)
- **Code:** preserved for reference

## What it explored

- Multi-tenant Laravel applications
- Central and tenant contexts
- Billing and provisioning
- PostgreSQL-backed data isolation
- Modular application structure
- Operational observability

> For current implementation decisions, use the active project documentation rather than this repository.
